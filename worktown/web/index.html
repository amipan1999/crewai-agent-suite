FAQ

よくあるご質問

体験で入力した内容はどう扱われますか？

AIチームへの指示のためだけに使い、この街では保存しません。個人情報や機密情報は入力しないでください。本番導入では御社の AWS アカウント内で処理する構成をご提案します。

AIの出力はそのまま業務に使えますか？

AIの出力は「部下が作った下書き」です。各体験で表示される「上司チェックポイント」のように、最終確認と判断は人が行う前提で業務に組み込みます。法務・税務などは専門家の確認が必要です。

ITに詳しい社員がいなくても導入できますか？

はい。診断から本番運用まで伴走し、社内で改善し続けられるよう担当者の育成も行います。

AWS 以外の環境でも対応できますか？

既存のシステム（Microsoft 365、Google Workspace、会計ソフト、SFA など）との連携を前提に設計します。基盤は AWS を推奨していますが、ご状況に合わせてご相談ください。

この街自体を自社用に使えますか？

はい。自社業務のミッションを追加した「社内版 AI WORK TOWN」を、研修やAI活用の社内浸透にご利用いただけます。
